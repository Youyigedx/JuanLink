DrawBox — vendored source notice
================================

The Kotlin sources in this directory tree (package `io.ak1.drawbox`) are
vendored from the open-source DrawBox drawing SDK and modified for use in
the JUAN Link (婵娟) collaborative drawing app.

Upstream
  Project:  DrawBox
  Homepage: https://github.com/akshay2211/DrawBox
  Author:   Akshay Sharma <fxn769@gmail.com>
  License:  Apache License, Version 2.0
  Vendor basis: upstream v2.1.0 (Maven coordinate io.ak1:drawbox:2.1.0)

Modifications (relative to upstream)
  - Vendored into this module instead of consuming the Maven artifact,
    because upstream is compiled with Kotlin 2.4.0 / Compose Multiplatform
    1.11.1, which the project's Kotlin 2.2.20 / Compose 1.9.3 toolchain
    cannot consume at the klib/metadata level.
  - Trimmed sources that the JUAN Link host does not use: DrawBoxController,
    input/ClipboardImage, input/DragDropImage, InlineTextEditor, and the
    web/wasmJs/iOS platform source sets.
  - Minor API adaptations to compile against Kotlin 2.2.20 and Compose
    Multiplatform 1.9.3.
