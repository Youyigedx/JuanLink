# 婵娟 JUAN Link — 8 小时长稳压测说明

> 目标：连续运行 8 小时无明显性能下降（内存/帧率/响应平稳），满足需求文档第十六条。

## 压测场景

1. **双端长连**：两个桌面实例经回环/局域网建立 P2P，保持连接 8 小时。
2. **持续绘制**：每 5 秒随机生成一条笔迹（随机工具/颜色/宽度），双向同步。
3. **图片流**：每 30 秒导入一张随机图片（分块同步）。
4. **周期性断线**：每 2 小时断开 2 秒（验证 <3s 无感恢复）。
5. **撤销风暴**：每 10 分钟批量撤销/重做 50 次。

## 观测指标（每 10 分钟采样）

| 指标 | 获取方式 | 合格线 |
|---|---|---|
| 内存 | JVM `MemoryMXBean` / 任务管理器 | 增幅 <20%/8h，无持续攀升 |
| 帧率 | 渲染层帧计数 | 稳定 ≥45fps |
| 延迟 | 状态栏质量指示 | 保持「优秀/正常」 |
| 同步一致 | 双端文档 stroke 数 | 最终一致（差 ≤ 0） |
| CPU | 任务管理器 | 平均 <30%（单核） |
