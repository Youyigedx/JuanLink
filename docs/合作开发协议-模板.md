## 导出为 Word / PDF

已生成两份可直接使用的成品（`out/` 为生成物目录，不入库）：

| 文件 | 用途 |
|---|---|
| `out/软著/合作开发协议.docx` | **编辑用**：可在 Word / WPS 中填写后打印 |
| `out/软著/合作开发协议.pdf` | **打印用**：5 页、A4、宋体正文／黑体标题、页脚「第 X 页 共 Y 页」 |

### 重新生成 PDF

```powershell
$env:PYTHONIOENCODING='utf-8'
python tools/make_agreement_pdf.py
```

依赖 `reportlab`（纯 Python，`pip install reportlab`）。

**为什么不直接由 docx 转 PDF**：本机既无 Word 也无 LibreOffice，
officecli 的 PDF 导出还需额外 exporter 插件，因此改用 reportlab 直接排版
（可精确控制中文字体、首行缩进与页脚页码）。

### 修改协议内容的注意点

两份文件的内容分别来自：

- **PDF**：`tools/make_agreement_pdf.py` 中的 `CONTENT` 列表
- **DOCX**：由 officecli 逐段构建，成品在 `out/软著/`

**两者不共享同一份源文本**。若修改条款，须**两边同步改**，或选定一份作为唯一权威版本
后重新导出另一份。改动后务必重新核对第四条、第五条等需填写项是否仍对齐。

### 排版中已规避的两个坑（重新生成时留意）

1. **中文行宽**：A4、页边距 3.17cm、12pt 时，每行约 34 个全角字符。
   填空下划线过长会溢出到下一行、留下孤立的「＿」。
   现有各行已按此上限校过长度，加长时请留意。
2. **中英混排断行**：reportlab 的 `wordWrap="CJK"` 必须开启，
   否则整句中文会被当作一个"词"，出现「4.」单独占一行、正文被抬到下一行的情况。
