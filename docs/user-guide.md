# Juan LinK — 用户操作说明

## 1. 快速开始（双人协作）

> 提示：首次启动可能弹出 **TURN 配置引导**——跨网协作需要配置 TURN 服务器（见 §8）；仅局域网直连可「跳过」。

### 创建协作（发起方）
1. 打开「Juan LinK」。
2. 点击顶栏「**创建协作**」。
3. 弹出连接面板：显示**二维码**与**配对码**（如 `5689-ABCD`）。
4. 等待对方加入。

### 加入协作（响应方）
1. 打开「Juan LinK」。
2. 点击「**加入协作**」。
3. 在输入框**粘贴对方二维码中的连接串**（局域网/回环测试场景），或扫描二维码。
4. 完成安全握手后自动进入共享画布。

> 提示：配对码的局域网自动发现（UDP 广播）为增强功能，当前版本请用连接串加入。

## 2. 实时绘画

- **画笔**：工具栏选择 铅笔 / 钢笔 / 毛笔 / 马克笔 / 荧光笔。
- **形状**：直线 / 矩形 / 圆形 / 箭头（拖拽定义范围，松手成图）。
- **橡皮**：以画布底色覆盖（视觉擦除）。
- **手形**：选择「手形」后拖拽 = 平移画布；在图片上拖拽 = 移动图片。
- **缩放**：滚轮以光标为中心缩放。
- **参数**：颜色（中式色板）、粗细（1-30）、透明度（0.05-1）。

## 3. 图片

- 点击「**导入图片**」，选择本地图片文件（PNG/JPG/BMP/WebP/GIF）。
- 图片进入画布中心，自动分块加密同步到对端。
- **移动**：手形工具拖拽。
- **缩放/旋转**：增强功能（阶段 7 后）。

## 4. 图层

- 右侧「图层」面板：新建、删除、上移/下移、显示/隐藏、锁定。
- 隐藏图层不绘制；锁定图层不响应编辑。

## 5. 撤销 / 重做

- 工具栏「撤销」「重做」；操作会同步到对端，双方历史一致。

## 6. 连接状态与质量

- 底部状态栏：连接状态 + 质量指示（优秀/正常/不稳定）。
- **优秀**：延迟 <80ms 且丢包 <1%，全功能实时。
- **正常**：延迟 80-200ms 或丢包 1-5%，系统自动优化（压缩/降频）。
- **不稳定**：延迟 >200ms 或丢包 >5%，禁止实时协作，提示改善网络。
- 网络中断时状态栏显示「网络中断，正在重连…」；中断较久显示「同步已暂停，正在恢复…」，恢复后自动补发断线期间的操作。

## 7. 断线保护

- 网络中断后自动重连；断线期间本端仍可绘画，恢复后自动补同步。
- 中断较久同步暂停，连接恢复后自动续传，无需手动重连。
- **永不自动关闭**协作；可随时点顶栏红色「断开连接」按钮主动结束。

## 8. 跨网连接与 TURN 配置

同一网段（同一 Wi-Fi / 局域网）两台设备走 TCP 直连，无需任何配置。
不在同一网络时（对称 NAT / 蜂窝网络），需要一台 TURN 中继服务器才能互通：

- **首次启动**：未配置 TURN 会弹配置引导（可关闭，先本地画画）。
- **协作前强制**：未配置就点「创建/加入协作」会弹**锁定引导**，只能保存至少一台服务器，或选择「跳过（仅局域网直连）」。
- **配置方式**：两端分别打开「设置」面板，添加**同一台** TURN 服务器（host/端口/用户名/密码）；桌面端也可直接编辑 `~/.juanlink/turn.json`（JSON 数组，支持多台）。
- **默认服务器**：内置公共测试服务器仅作 fallback（通常不可用），跨网前请务必配置自己的服务器。

## 9. 安全须知

- 端到端加密（X25519 + AES-256-GCM），画布数据只存在双方设备。
- 跨网时数据经你配置的 TURN 服务器**加密转发**（服务器仅中继密文，无法窥探内容）；局域网直连则全程无服务器参与。
- 二维码/配对码仅用于建立直连，一次有效、自动过期（默认 3 分钟）。

## 10. 常见问题

| 问题 | 解决 |
|---|---|
| 无法连接 | 确认双方在同一局域网；或粘贴完整连接串 |
| 连接串无效 | 复制二维码面板中的完整内容 |
| 图像不同步 | 检查网络质量指示，回到「优秀/正常」 |
